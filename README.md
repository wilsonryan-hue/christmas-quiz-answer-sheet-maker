# Free Christmas quiz answer sheet maker (one HTML file, nothing stored)

Make printable team answer sheets for a Christmas pub quiz, family quiz, school or office quiz. Pick the number of rounds and questions, press a button, and print. No sign-up, no server, no cookies, no build step: it is one `index.html` file.

**Use it now, no install:** download `index.html` and open it in any browser, or see the ready-made sheets at [tchworks.co.uk/free/christmas-quiz-answer-sheets](https://www.tchworks.co.uk/free/christmas-quiz-answer-sheets/?utm_source=github&utm_medium=repo&utm_campaign=quiz-sheet-repo).

## What it prints

- One team answer sheet per round (1 to 12 rounds, 5 to 20 questions each), with a team name line, numbered answer lines and a round total box.
- Optional round names, typed one per line, shown in each sheet heading.
- Optional joker box, for teams that want to double their points on one round.
- Optional small score box beside each answer line, for swap-and-mark rounds.
- Optional tie-breaker sheet (closest number wins).
- Optional quizmaster answer key with blank numbered lines for every round.
- Optional scoring grid for 2 to 24 teams with a column for each round, the tie-break and the total.
- Four styles: red, green, midnight blue and plain black, which saves ink.
- Typed text is shown as text only, never run as code.

## Use it

Open `index.html`, set your rounds and questions, press **Make my sheets**, then **Print**. Print at 100 percent on A4. One round prints per page, so print only the pages you need and photocopy for more teams. The file works offline.

## Self-host

Put `index.html` on any static host (GitHub Pages, Netlify, a school intranet). There is nothing to configure.

## Running a quiz with these sheets

1. Give each team a sheet per round, a pen and a team name.
2. Read each question twice. Allow the time you chose before moving on.
3. Swap sheets between teams to mark, or collect them and mark yourself.
4. Fill in the scoring grid after each round. Use the tie-breaker if two teams finish level.
